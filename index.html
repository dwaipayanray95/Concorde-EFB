Official Website

Supersonic flight planning, done right.

Concorde EFB is a free, realistic electronic flight bag built for the DC Designs Concorde in Microsoft Flight Simulator — cruise-climb mission profiles, METAR-corrected takeoff and landing performance, interactive checklists, and a live SimConnect flight monitor, all in one desktop app.

What it does

🛫

Cruise-Climb Mission Profile

Segmented climb, supersonic acceleration, cruise-climb, and descent modeling for realistic trip fuel and ETE.

📊

Live Performance Calculator

Takeoff and landing V-speeds and runway feasibility, corrected for live METAR wind, QNH, and temperature.

✅

Interactive Checklists

Full cold-and-dark-to-shutdown Concorde checklist flow, synced with live V-speeds once a plan is loaded.

📡

Live Flight Monitor

A glass-cockpit style avionics panel streaming real-time telemetry from MSFS over SimConnect.

🗺️

Offline Airport Database

39,000+ airports and runways bundled in-app — flight planning works fully offline.

✈️

SimBrief Import

Pull route, fuel, callsign, registration, and runway data straight from your SimBrief OFP.

About the project

Concorde EFB started as a small performance calculator and has grown into a full Flutter desktop application — built and maintained in the developer's spare time as a free companion for the flight sim community. It targets Windows, macOS, and Linux, with an optional bundled SimConnect bridge so Flight Monitor works without installing anything extra.
